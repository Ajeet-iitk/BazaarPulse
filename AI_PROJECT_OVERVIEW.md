## 📌 1. Project Purpose & Summary
This project transforms a private Google Spreadsheet containing personal everyday expense and price records (tab name **"Price"**) spanning across **Delhi, Ghazipur, and Varanasi** (April 2025 to November 2026) into a high-performance, dynamic, modern **Marketplace & Lifestyle Web Application**. The bazaar itself is a walkable 3D street whose layout, stalls, awnings, lamps and decorations are generated by a C++ scene builder and rendered with Three.js/WebGL.

## ⚙️ 3. Key Architecture & Features Implemented

### A. Real-Time Data Pipeline & Offline Resilience
- **Source Sheet:** Google Sheets ID `1hwVcnyeRMP8Zh_G32qj-9qftLvwJ8308KE55PD9148c`, tab `Price`.
- **Fields Handled:** `Date`, `Place`, `Item`, `Description`, `Remark`.
- **Hybrid Data Model:**
  - `data.json` holds all 88 parsed records extracted via the `gsheets` CLI tool.
  - `index.html` embeds this dataset into memory (`EMBEDDED_RECORDS`), guaranteeing **100% offline functionality** when loaded directly via `file:///` without CORS blocks.
  - Also attempts dynamic `fetch('data.json')` for seamless hot-reloading when hosted on an HTTP server.
  - Uses browser `localStorage` (`bazaar_user_entries`) to allow users to add new price entries dynamically.
  - Includes a one-click **"Export CSV"** function to download the complete database.

### B. Marketplace UI/UX & Styling
- **Indian Bazaar Theme:** Warm mandi cream/sand surfaces for day mode, deep aubergine/plum for night mode, with marigold, rani pink, peacock teal and indigo accents.
- **Motifs & Texture:** Rangoli watermarks, marigold toran fringes under the navbar, petal drift, warm glass panels, section underlines and scroll-reveal transitions.
- **Navigation:** Sticky header with an animated active glider, scroll-spy, shrink state, a responsive hamburger drawer, smooth section offsets and real day/night switching.
- **Scrolling Market Ticker Tape:**
  - Endless scrolling top marquee featuring live rates for staples: Apples (₹120/kg), Full Cream Milk (₹35/0.5L), Eggs (₹10/pc), Delhi Metro (₹18), UP Roadways bus (₹151), etc., with delta tags.
- **Compact Bazaar Ribbon:** A single pill-shaped live ledger under the hero (items, mandi hubs, 3D scene, Sheet link, Sync, Export) instead of separate KPI cards and a repeated sheet-sync strip.
- **Walkable 3D Street:** A full WebGL bazaar replaces the old CSS stall cards and the duplicated Explore hub. Shops are visited by clicking their 3D stall, searching, or using the walk controls.

### F. High-Performance C Engine
- **File:** `sheet_engine.c`
- **Compiler:** `gcc -O3 -o sheet_engine.exe sheet_engine.c`
- **Capabilities:** Fast memory scanner for currency symbols (`Rs`, `₹`), price extraction, and quick-sort item comparisons.

### G. Real 3D Bazaar Engine (C++ → WebGL)
- **Authoring:** `bazaar3d.cpp` is the single source of truth for the 3D world. It computes the street, 12 interactive shop stalls, 11 decorative filler stalls, lamps, festoon bunting, rangoli medallions, skyline, props and the end gate.
- **Build:**
  ```powershell
  g++ -O2 -std=c++17 bazaar3d.cpp -o bazaar3d.exe
  .\bazaar3d.exe | Out-File -FilePath bazaar3d_scene.js -Encoding utf8
  ```
- **Output:** `bazaar3d_scene.js` assigns `window.BAZAAR_SCENE` (pure JSON-like data). It is auto-generated — do not hand-edit it.
- **Rendering:** `initBazaar3D()` in `index.html` consumes the scene graph with a locally vendored `three.min.js` (r152 UMD). It builds shop geometry, canvas-painted awnings/toran/signs/price tags, keeper characters, produce, lamps, bunting, skyline, rangoli decals and the gate.
- **Interaction:** Drag to look, wheel to walk, W/S/A/D/E keys, on-screen walk/auto/enter buttons. Raycast picking walks the camera to a stall and auto-opens the shop modal. Hover/near rings highlight stalls, and search filters hide non-matching 3D shops.
- **Day/Night:** `bazaar3D.applyTheme()` swaps sky shader colors, fog, lights, star visibility, lamp glow, skyline facade/sunlit road textures and exposure to match the page theme.
- **Performance:** The old CSS diorama is hidden; `renderStreet()` short-circuits to a small near-shop calculation when WebGL is active. Mobile uses a capped pixel ratio and no antialiasing.

## 🛠 4. How Future AIs Should Maintain or Extend This Project

1. **Adding New Sheet Rows to `index.html`:**
   - Run `gsheets readonly read 1hwVcnyeRMP8Zh_G32qj-9qftLvwJ8308KE55PD9148c "Price!A1:Z150" --json > data.json`.
   - Run the PowerShell script: `powershell -ExecutionPolicy Bypass -File .\embed_data.ps1`.
   - This automatically regenerates the embedded data array in `index.html`.

2. **Connecting Remote Live Write-Back (Optional):**
   - If the user wants `saveNewPriceEntry()` to directly append rows to the remote Google Sheet, set up a Google Apps Script Web App (`doPost(e)`) and attach its URL into the `fetch()` handler in `index.html`.

3. **Styling and Component Integrity:**
   - Keep dark/light mode CSS variables synced between `:root` and `[data-theme="light"]`.
   - When modifying text elements, always check that the matching keys in the `I18N` object (`en`, `hi`, `eh`) are updated.
   - Keep the shop data in `SHOPS` (index.html) and the C++ scene IDs in `bazaar3d.cpp` aligned: the 3D shop group IDs (`fruit`, `dairy`, …) must match `SHOPS[].id`.

4. **Editing the 3D Bazaar:**
   - Change layout, stall positions, colors, decor, lamps, skyline or the gate in `bazaar3d.cpp`, then rebuild `bazaar3d.exe` and regenerate `bazaar3d_scene.js` with the commands in section G.
   - Keep `three.min.js` and `bazaar3d_scene.js` loaded immediately before the main inline app script; script order is required by `initBazaar3D()`.
   - The camera mapping is `camera.z = -STREET.playerZ * 0.05263158` (20 world units per 380 street units). The C++ `playerZScale` field in `meta` documents this.
   - Do not reintroduce the old `.street-directory` chips or text-based stall cards; navigate via the 3D stalls, search, or the HUD controls.
